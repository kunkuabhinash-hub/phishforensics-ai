# phishforensics-ai

> Don't just detect the phishing. Reconstruct the attack.

## Project

PhishForensics AI is an explainable AI-based phishing investigation and awareness platform.

The system analyzes suspicious content, identifies possible attacker intent and manipulation techniques, reconstructs a potential attack flow, and teaches the user how to recognize similar attacks.
